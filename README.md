# TaskNest — Mini Task Manager

A simple, beginner-friendly full-stack task management website built with **React (Vite)**, **Node.js (Express)**, and **SQL (SQLite)**.

The project is organized in the `tasknest/` directory:
- `tasknest/backend/` — Express REST API with an embedded SQLite SQL database (zero external installation required!)
- `tasknest/frontend/` — React frontend with Vite & Vanilla CSS

For full setup and running instructions, please see:
👉 [**tasknest/README.md**](./tasknest/README.md)

### Quick Start

1. **Backend:**
   ```bash
   cd tasknest/backend
   npm install
   npm start
   ```

2. **Frontend:**
   ```bash
   cd tasknest/frontend
   npm install
   npm run dev
   ```
